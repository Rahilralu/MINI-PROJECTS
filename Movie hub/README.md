# 🎬 MovieArea12

A movie discovery web app built with **Vite + React**, powered by **TMDB API** and **Appwrite**.  
Deployed on **Netlify**: [Link Here](https://moviearea12.netlify.app/)

---

## ✨ Features
- 🔍 Search movies from **TMDB**
- 🎥 Trending & popular movies list
- 📖 Movie details page
- 📊 Appwrite database integration (track user interactions, counts, etc.)
- ⚡ Fast build with **Vite**
- ☁️ Deployed with **Netlify**

---

## ⚙️ Tech Stack
- **Frontend**: React (Vite)
- **Backend/DB**: Appwrite (Cloud)
- **API**: [The Movie Database (TMDB)](https://www.themoviedb.org/documentation/api)
- **Deployment**: Netlify
